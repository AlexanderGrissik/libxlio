\doxysubsubsection{Detailed Description}
High-\/performance data transmission functions. 

The XLIO Ultra API provides efficient transmission capabilities with zero-\/copy support and flexible batching options.\hypertarget{group__xlio__tx_tx_properties}{}\doxysubsubsection{\texorpdfstring{TX Flow Properties}{TX Flow Properties}}\label{group__xlio__tx_tx_properties}

\begin{DoxyItemize}
\item Non-\/blocking operation
\item No partial write support -\/ accepts all data unless memory allocation fails
\item Zero-\/copy completion callbacks for memory management
\item Inline send operations support for small data
\item Data aggregation with explicit flush control
\end{DoxyItemize}\hypertarget{group__xlio__tx_tx_limitations}{}\doxysubsubsection{\texorpdfstring{TX Flow Limitations}{TX Flow Limitations}}\label{group__xlio__tx_tx_limitations}

\begin{DoxyItemize}
\item Currently, data can be pushed to wire in the RX flow regardless of the flush logic
\item Avoid using \doxylink{group__xlio__tx_gac300e5a65b6a40e915374a0260903a47}{xlio\+\_\+socket\+\_\+flush()} for a XLIO\+\_\+\+GROUP\+\_\+\+FLAG\+\_\+\+DIRTY group
\item For a XLIO\+\_\+\+GROUP\+\_\+\+FLAG\+\_\+\+DIRTY group, usage of XLIO\+\_\+\+SOCKET\+\_\+\+SEND\+\_\+\+FLAG\+\_\+\+FLUSH is limited, it\textquotesingle{}s better to avoid using them both simultaneously. 
\end{DoxyItemize}

Flush pending data on a socket. 

Forces transmission of any data queued on the socket. XLIO aggregates data by default for efficiency and user logic simplification.

This function doesn\textquotesingle{}t guarantee immediate transmission, because TCP algorithms and congestion/flow control may affect transmission.

Initialize the XLIO Ultra API. 

This function must be called before using any other XLIO Ultra API functions. It\textquotesingle{}s a heavy operation that sets up the internal state, allocates resources, and configures the system for high-\/performance networking.

\begin{DoxyNote}{Note}
This function is not thread-\/safe. However, subsequent serialized calls will exit successfully without performing any action.
